# 100 Days of Kloud ☁️

## About This Challenge

Welcome to my **100 Days of Kloud** journey!

I'm completing hands-on AWS labs through **KodeKloud** to strengthen my cloud computing knowledge, gain practical experience, and continue building toward my goal of becoming a Cloud/DevOps Engineer.

This challenge is about learning by doing, improving my troubleshooting skills, and becoming more confident working with AWS infrastructure independently.

## ☁️ Technologies & Skills

Throughout this challenge, I'll be practicing:

- Amazon Web Services (AWS)
- Virtual Private Cloud (VPC) & Networking
- EC2 & Compute Services
- Identity & Access Management (IAM)
- Cloud Security
- Storage & Infrastructure
- AWS CLI & Troubleshooting

## 🎯 My Goals

- Complete 100 hands-on AWS labs.
- Strengthen my understanding of cloud infrastructure and networking.
- Become more comfortable navigating AWS services and documentation.
- Practice troubleshooting and solving problems independently.
- Document my progress and key takeaways.

## 📚 Learning Approach

1. Review the lab scenario and identify the requirements.
2. Research AWS documentation and unfamiliar concepts.
3. Implement the solution using the AWS Console or CLI.
4. Verify the configuration and troubleshoot any issues.
5. Document what I learned.
