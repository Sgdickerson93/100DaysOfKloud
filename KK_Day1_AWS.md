# Create an AWS KeyPair

What is a keypair?

A keypair  key pair, consisting of a public key and a private key, is a set of security credentials that you use to prove your identity. It is also an example of asymmetric encryption. a method of securing data using a mathematically linked pair of keys: a public key that can be shared with anyone, and a private key that is kept strictly secret by its owner.


To create a keypair:

I started by looking up AWS documentation on how to create a key pair: https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/create-key-pairs.html

I created the keypair by EC2 instance. I logged in using the given credentials and search for "Key pairs". After search i clicked "create key pair" and begin the process of creation. I entered the name, selected the type, and created the pair. I made sure to be in east-us-1 region as well.

Once the key pair created it downloaded to my computer to save in a safe place.
